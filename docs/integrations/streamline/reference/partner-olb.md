### Partner OLB APIs

The Partner OLB portion of the integration relies on Streamlines direct API.\

These API's require token_key and token_secret parameters when called which are linked to your IP allowed list within this Portal.

Thing you can do:

- API Token Renewal
- Query Booked Reservations
- Live Price Quote
- Book a Reservation
- Fast Availability Check

You can call these API's formatted in JSON or XML using the respective Streamline VRS endpoint below:

### API Endpoints

JSON ENDPOINT

https://web.streamlinevrs.com/api/json XML ENDPOINT

https://web.streamlinevrs.com/api/1.1
