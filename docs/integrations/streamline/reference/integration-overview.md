### Partner Listings/OLB Integration Overview

### Welcome to the Streamline Listings/Partner OLB integration:

Together, the Listings XML feed and Partner OLB API's will enable you to fully manage an integrated property managers opted-in units. This combination allows online bookings originating from your platform to be booked directly into the Streamline PMS. Features:Listings xml feeds enable you to programmatically create listings for properties that you want to post on your platform. The indexes within the feeds provide the following content.

· Listing content

· Structured Rates - Nightly or length-of-stay (LoS)

· Taxes and Fees

· Rental agreements/Cancellation policies

· Availability

· Lodging Configurations

Partner OLB API's provide the following services:

· Fast Availability Check

· Price Quote

· Booking Service

· Booked Reservations Query

· API Token Management,
