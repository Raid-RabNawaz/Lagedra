# Price Quote API

Captured from the Streamline Partner X portal on 2026-08-27. Example credential values are
replaced with `YOUR_TOKEN_KEY`, `YOUR_TOKEN_SECRET`, and `YOUR_DISTRIBUTOR_CODE`.

Source: `https://partner.streamlinevrs.com/apidocs/general/Partner OLB/Price-Quote-API`

---
This Partner OLB API method allows you to get a live price quote from Streamline related to the taxes, fees and rates associated to your unique reservation type and "distributor_code".
